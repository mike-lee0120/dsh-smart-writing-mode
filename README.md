# dsh-smart-writing-mode

基于 DeepSeek Harness（DSH）的「智能写作模式」Agent preset —— 面向小说与剧本创作的专业写作助手。

内置「类型 → 结构 → 节拍 → 叙事气质」创作体系与长篇小说增量创作协议，支持创意策划、小说、电影/电视剧/话剧剧本、微短剧、小说改编剧本与润色修订。

> English version: [README.en.md](README.en.md)

## 特性

- **6 个专业写作 Skills**：覆盖策划、小说、电影剧本、微短剧、改编、润色全流程。
- **类型/结构/节拍/叙事气质体系**：短剧 8 大核心类型、电影 8 大标准类型、经典剧作结构大全、电影 120 分钟 15 节拍、短剧 10 节拍、作家/编剧风格库（references 内容库）。
- **长文本支持**：长篇小说（如 40 万字）采用「增量落盘 + 分章文件 + 单一事实源设定表」创作，正文持久化到磁盘。
- **全量工具能力**：保留 `standard` 的文件读写、Shell、后台任务、计划、子代理、工作流、联网研究等能力。
- **可扩展**：加 skill、改 persona、挂自定义工具只需编辑对应文件。

## 快速开始

```bash
./install.sh
```

安装后：新建会话 → 在模式选择器选择「智能写作模式」→ 给出创意即可。

示例：

> 我想写一部逆袭爽剧短剧：女主被退婚后意外觉醒医术金手指，一路打脸复仇。

助手会加载 `short-drama-writing`，按「定类型 → 爽剧打脸结构 → 10 节拍 → 对标叙事气质」产出分集大纲（每集带钩子）与剧本。

## 创作流水线

> 定类型 → 选结构 → 套节拍 → 对标叙事气质 → 出大纲/成稿

- **定类型**：从短剧 8 大核心类型 / 电影 8 大标准类型中选型。
- **选结构**：从《经典剧作结构大全》挑适配结构。
- **套节拍**：电影套 15 节拍、短剧套 10 节拍逐拍落盘。
- **对标叙事气质**：从作家/编剧风格库选最贴近的作家作参照。

## 内置 Skills

| Skill | 作用 |
|---|---|
| `story-development` | 创意策划与大纲：梗概、主题、世界观/人物、经典剧作结构大全、分章/分场大纲、项目目录 |
| `novel-writing` | 小说创作：文体技法、题材专项、长篇小说增量创作协议（分章落盘 + 单一事实源设定表） |
| `screenplay-writing` | 电影/电视剧/话剧剧本：标准格式、8 大电影类型、120 分钟 15 节拍、风格参照（编剧对标） |
| `short-drama-writing` | 微短剧创作：短剧 8 大核心类型、类型→结构映射、短剧 10 节拍、单集卡时量化、风格参照（网文作家对标） |
| `novel-to-screenplay` | 小说改编剧本：提炼/取舍/重构/转写，适配电影 15 节拍或短剧 10 节拍 |
| `writing-revision` | 润色与修订：分层校对、跨章一致性、剧本节拍/钩子复核、长文本全局审校 |

## 知识体系

- **类型学**：短剧 8 大核心类型（逆袭爽剧 / 复仇 / 甜宠 / 虐恋 / 狗血伦理 / 悬疑 / 玄幻异能 / 现实年代）、电影 8 大标准类型（动作 / 喜剧 / 爱情 / 悬疑 / 惊悚 / 科幻 / 犯罪 / 剧情）。
- **结构学**：经典剧作结构大全（三幕、英雄之旅、八步叙事、救猫咪、五幕、极简爆款、悬疑三幕反转、爽剧打脸）。
- **节拍表**：电影 120 分钟 15 节拍、短剧通用 10 节拍 + 专属注意事项 + 单集卡时量化。
- **风格参照（作家/编剧对标）**：作家风格库（金庸 / 刘慈欣 / 东野圭吾 / 莫言 等）、编剧风格库（莎士比亚 / 契诃夫 / 曹禺 / 刘和平 等）、网文作家风格库（唐家三少 / 猫腻 / 天蚕土豆 等）。

## 内容库（references）

大型查询型资料（作家/编剧风格库等）不放进 SKILL.md，而是作为各 skill 的 `references/*.md` 内容库，按需读取、可无限扩充：

```
skills/
  novel-writing/references/作家风格库.md
  screenplay-writing/references/编剧风格库.md
  short-drama-writing/references/网文作家风格库.md
```

- SKILL.md 只留方法论 + 指向内容库的指针；agent 用到哪类才读哪个文件。
- 扩充：按库底部的「条目模板」加一条即可，无需改 SKILL.md，也不触发 skill catalog 失效。

## 长文本支持

长篇小说（如 40 万字）采用「增量落盘 + 分章文件 + 单一事实源设定表」创作：

- 正文永远写进 `正文/第00N章.md`，不进对话上下文。
- `设定/`（人物表 / 时间线 / 伏笔表）随写随更新，作为一致性唯一事实源。
- `进度.md` 驱动续写，`goal` 追踪总量，断轮/重启后凭进度表续写。

详见 `novel-writing` 的「长篇小说增量创作协议」与「跨章一致性自查流程」。

## 使用示例

| 需求 | 示例提示词 |

| 短剧 | 「写一部 60 分钟、30 集的逆袭爽剧短剧，女主被退婚后觉醒神医金手指打脸复仇」 |

## 目录结构

```
dsh-smart-writing-mode/
  agent.cordis.yml      # 组合文件（standard 基底 + 写作 persona + 内置 skills）
  preset.yml            # 显示元数据
  install.sh            # 安装脚本
  skills/<name>/SKILL.md          # 方法论
  skills/<name>/references/*.md   # 内容库（作家/编剧风格库等）
```

## 安装

```bash
./install.sh
```

等价地，把本目录（排除 `.git` 与 README）复制到 `${DSH_HOME:-$HOME/.dsh}/.agent-presets/writing/`。安装后新会话即可在模式选择器看到「智能写作模式」。

## 扩展

- **加 Skill**：在 `skills/<name>/SKILL.md` 新建（frontmatter 必含 kebab-case `name` 与 `description`），目录名与 `name` 一致。
- **扩充内容库**：编辑 `skills/<name>/references/*.md`，按库底部的「条目模板」加条目。
- **改 Persona**：编辑 `agent.cordis.yml` 的 `persona` 行。
- **自定义工具**：新增 `.mjs` 文件并以相对路径行（`./tool-xxx.mjs`）挂载，参照社区预设 `anchored-standard` 的 `tool-bootstrap.mjs`。
