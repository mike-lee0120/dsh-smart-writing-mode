# 小说创作（novel-writing）

从 `story-development` 产出的大纲与设定出发，把小说一章章写出来、写到位。长篇不是一次写成的，而是按「增量落盘」协议持久化到文件、逐章推进。

## 创作流水线

大纲 → 细纲 → 分章起草 → 修订（修订细节见 `writing-revision`）。

1. **读大纲与设定**：动笔前先读 `大纲/` 与 `设定/`（人物表、时间线、伏笔表）。
2. **细纲**：把本卷/本段大纲细化到「本章要发生什么、推进哪条线、留什么钩子」。
3. **分章起草**：逐章写进 `正文/第00N章.md`（见「长篇小说增量创作协议」）。
4. **修订**：写完一段后自查一致性（人名、时间线、伏笔），再交 `writing-revision` 打磨。

## 文体技法

- **叙事视角（POV）**：全知 / 第三人称限知 / 第一人称；一部作品保持一致，切换要明确且有目的。
- **文风与声音**：先定「谁在讲、用什么语气」，网文偏白描快节奏，严肃文学偏克制凝练；全文统一。
- **场景与画面感**：show, don't tell——用动作、细节、对白呈现，少用概括性叙述。
- **对话**：推动剧情或塑造人物，口语化、有潜台词；避免「为了交代信息而说话」。
- **节奏**：文戏张弛、武戏提速；短句加快、长句放缓。
- **章节钩子**：每章结尾留悬念/反转/未解问题，勾住读者。
- **伏笔与回收**：埋设记入「伏笔表」，回收时回写，避免烂尾。

## 题材专项

- 悬疑：谜面 + 误导 + 反转，线索公平、逻辑自洽（可参考 `story-development` 的「悬疑三幕反转结构」）。
- 言情/甜宠/虐恋：情感动机要成立，甜要自然、虐要有因，避免为虐而虐。
- 玄幻/奇幻/科幻：世界观规则自洽、能力有代价，升级/系统要有成长曲线。
- 都市/现实/年代：细节真实、贴近生活，爽点与逻辑并重。
- 历史：尊重史实大框架，虚构部分合理标注。
- 爽点类型（逆袭/复仇/打脸/扮猪吃虎/身份曝光等）可借鉴 `short-drama-writing` 的「短剧 8 大核心类型」作为套路与爽点参考，但叙事用小说文体而非剧本格式。

## 长篇小说增量创作协议

长篇（如 40 万字）正文永远落盘、不进对话。遵守以下协议：

### 项目目录（由 `story-development` 建立，续写时补全）

```
<作品名>/
  大纲/      梗概.md、分章大纲.md、结构.md
  设定/      世界观.md、人物表.md、时间线.md、伏笔表.md
  正文/      第001章.md、第002章.md …
  进度.md
```

### 单一事实源

- 人物表 / 时间线 / 伏笔表是「一致性唯一事实源」，每次写新章都要先读、写后要回写更新。
- 正文只写进 `正文/` 文件，不把整章塞进对话；对话里只保留大纲、设定、最近几章用于上下文。

### 每章起草流程

1. 读 `进度.md` 确定「下一章」；读 `分章大纲.md` 对应章节要点。
2. 读 `人物表.md` + `时间线.md` + `伏笔表.md` + 最近 3–5 章正文（保证衔接与文风一致）。
3. 写本章到 `正文/第00N章.md`（章号补零，保持排序）。
4. 更新 `进度.md`（已写章、下一章、累计字数）；有新埋设/回收则更新 `伏笔表.md`；人物/时间线有变化则回写设定。

### 字数预算

- 常规：每章 2000–4000 字；40 万字 ≈ 100–200 章。
- 网文日更型：每章 2000–3000 字；中短篇按篇幅自行规划章节数。
- 先定「总目标字数 + 章节数」，写进 `进度.md` 作为总量追踪依据。

### 长跑机制

- 用 `goal` 工具追踪「写完这部作品」的总目标；断轮/重启后凭 `进度.md` 续写，正文不丢。
- 每轮只复读所需片段；上下文压缩（compaction）不影响已落盘正文。
- 单次输出有限，一章可分多次写，写完一段就落盘，不要攒在对话里。

### 委派策略

- 风格连贯优先：顺序逐章写，父代理维护一致性。
- 赶进度可 `subagent_fork`/`subagent` 起草单章草稿：给它「大纲要点 + 人物表摘要 + 前文关键片段 + 目标字数」，父代理负责回读、统一文风、审校一致性后落盘。

### 跨章一致性自查流程（每章必做）

每写完一章，先做「单章自检」，再视篇幅做「跨章抽查」：

**单章自检**（写完即做）：
- 人名/称呼：本章人物名、外号、称谓与前文一致（用 grep 在 `正文/` 里查关键词复核）。
- 时间线：本章时间与前文时间锚点无矛盾（对照 `设定/时间线.md`）。
- 地点/地理：场景、位置关系前后一致。
- 能力/设定：金手指、世界观规则不越界、不「升级失忆」（对照 `设定/世界观.md`）。
- 伏笔：新埋设即时登记 `伏笔表.md`，本章回收的伏笔即时标「已回收」。

**跨章抽查**（每写完 5–10 章做一次）：
- 用 grep 检索关键人名/地名/道具/称号，检查拼写、称呼、时间跨度的前后一致。
- 重读 `伏笔表.md`，确认没有「埋了不回收」或「回收了没登记」。
- 抽读最近 3 章与本章衔接处，检查文风与情绪是否连贯。

**全篇通读**（完稿后）：可 `subagent_fork` 分批审校（每批若干章，对照 `设定/`），父代理汇总修订——详见 `writing-revision` 的「长文本全局审校」。
