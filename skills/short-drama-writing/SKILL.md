# 微短剧创作（short-drama-writing）

面向竖屏微短剧：单集 1–3 分钟、总时长 30–120 分钟、强钩子、高密度爽点/冲突。核心是「快节奏 + 每集钩子 + 极致人设」。传统电影/电视剧剧本用 `screenplay-writing`。

## 短剧形态与平台规则

- 单集 1–3 分钟，总时长 30–120 分钟（通常 30–60 分钟最适配）。
- 竖屏、强钩子：10 秒内锁住观众，避免划走；除结局外每集必留反转/悬念。
- 人设极致鲜明、台词精炼、每 1–2 分钟一个爽点/冲突，杜绝平淡。

## 短剧平台认可 8 大核心类型（按剧情套路分类，非题材）

1. **逆袭爽剧**——重生、赘婿、废柴崛起、扮猪吃虎、打脸升级。
2. **复仇剧**——隐忍归来、手撕仇人、阴谋翻盘、报仇雪恨。
3. **甜宠剧**——霸总宠溺、先婚后爱、高甜撒糖、萌宝助攻。
4. **虐恋剧**——追妻火葬场、误会重重、相爱相杀、虐身虐心。
5. **狗血伦理剧**——真假千金、婆媳矛盾、出轨撕逼、家产争夺。
6. **悬疑剧**——探案解谜、身份谜团、连环反转、阴谋真相。
7. **玄幻异能剧**——系统、神医、透视、玄学、修仙、金手指。
8. **现实/年代剧**——年代致富、家庭温情、职场成长、市井生活。

## 类型 → 适配结构映射

结构定义见 `story-development`《经典剧作结构大全》。

| 类型 | 适配结构 |
|---|---|
| 逆袭爽剧 | 爽剧打脸结构（受辱→金手指→打脸→更大危机→终极翻盘→身份曝光） |
| 复仇剧 | 爽剧打脸结构 / 极简爆款（目标-阻碍-行动-危机-结局） |
| 甜宠剧 | 三幕式 + 每集情感小反转（高甜撒糖 + 结尾钩子） |
| 虐恋剧 | 三幕式（相爱相杀）+ 追妻火葬场节奏（虐→悔→追→合） |
| 狗血伦理剧 | 极简爆款结构（冲突密集，每集一个强冲突钩子） |
| 悬疑剧 | 悬疑三幕反转结构（谜面→误导+伪解答→真相反转+闭环） |
| 玄幻异能剧 | 英雄之旅（升级流）/ 爽剧打脸（金手指流） |
| 现实/年代剧 | 八步叙事结构 / 五幕剧 |

## 短剧通用完整版 10 节拍

严格适配「单集 1–3 分钟、总 30–120 分钟」：压缩时间、强化钩子、每集必留悬念。括号内为「单集内时间 / 总剧情时间」。

1. **开场画面（单集 0–30 秒，总 0–1 分钟）**——极致抓眼、快速定调，10 秒锁住观众。完全放弃铺垫，直接抛强冲突/强视觉/强反差，突出「第一眼记忆点」。
   - 示例：爽剧女主被当众羞辱、撕碎婚约；悬疑剧凶案现场特写（带血信物、模糊凶手背影）；甜宠剧男主意外救下遇险女主；动作剧主角被追杀、绝境反击瞬间。
2. **主题呈现（单集 30 秒–1 分钟，总 1–2 分钟）**——直截了当点题，1 分钟内明确核心剧情，不隐晦不拖沓。通过台词/旁白/细节点明核心（复仇/逆袭/追爱/解谜）。
   - 示例：女主攥拳「害我的人，我一个都不会放过」；男主对女主背影「这一次，我不会再让你走」；侦探拿起信物「这不是意外，是谋杀」。
3. **铺垫（单集 1–1.5 分钟，总 2–5 分钟）**——快速立人设、铺背景，建立共情。1–2 个关键细节交代主角核心需求/缺陷/处境，同时铺垫核心矛盾，避免冗长。
   - 示例：女主看着母亲病历单，想起反派逼死父亲的场景；甜宠女主独自吃生日蛋糕，闪过孤独过往。
4. **催化剂（激励事件）（单集 1.5–2 分钟，总 5–8 分钟）**——打破平静、迫使立刻行动，无多余犹豫。事件直接有冲击力，主角快速做出选择，衔接主线。
   - 示例：女主收到威胁信、得知母亲被绑架，立刻决定反击；侦探收到匿名线索，当即出发调查。
5. **争执/挣扎（单集 2–2.5 分钟，总 8–10 分钟）**——简化冲突、强化动机，避免行动突兀。1 句关键台词、1 个动作体现犹豫/矛盾，快速衔接入局。
   - 示例：闺蜜劝阻「你斗不过他的」→「为了我妈，我必须试」；助手提醒「可能是陷阱」→「就算是陷阱，我也要去」。
6. **进入主线（单集内完成，总 10–15 分钟）**——正式入局、开启主线。下决心后立刻行动，进入全新场景，明确单集/阶段核心任务。
7. **爽点/看点释放（单集核心，占比 30%，总 15–60 分钟）**——满足即时需求、留住观众，对应商业片「游戏时间」。每 1–2 分钟释放一个小爽点/看点，服务于主线。
   - 示例：打脸小喽啰、揭露小阴谋；男主保护女主、高甜互动（递水/挡雨）；找到关键线索、破解小谜题。
8. **单集反转/悬念（单集结尾前 30 秒，贯穿除结局外所有集）**——制造钩子、吸引追更，对应「中点反转」。每集结尾必留反转/悬念，贴合主线，不强行噱头。
   - 示例：刚打脸小喽啰，转头发现反派就在身后盯着她；刚示好，女主看到男主和别的女人亲密同框；线索指向自己最信任的人。
9. **高潮决战（全剧倒数 1–2 集，总 60–110 分钟）**——终极对抗、解决核心矛盾、释放情绪。压缩决战（单集 3 分钟内），聚焦核心矛盾，直接呈现终极对决。
   - 示例：女主当众揭露反派罪证、身败名裂；主角解开误会、确认关系；侦探与凶手正面对峙、真相揭晓。
10. **结局（全剧最后 1 集结尾，总 110–120 分钟）**——闭环收尾、交代归宿、留下余味，不烂尾。1 分钟内交代归宿、弥补缺陷、达成心愿，可留轻微续集伏笔。

## 短剧专属注意事项

1. **时间控制**：单集每个节拍严格卡时，总时长按平台要求调整（通常 30–60 分钟最适配）。
2. **钩子密度**：除结局外，每集必留反转/悬念，每 1–2 分钟必有爽点/冲突，杜绝平淡。
3. **人设鲜明**：人设要极致（爽剧女主清醒狠飒、甜宠女主软萌可爱），让观众快速记住。
4. **台词精炼**：每句台词都服务剧情/人设/冲突，避免废话。
5. **适配平台**：抖音/快手短剧更侧重爽点和悬念，长视频短剧可适当增加细节铺垫。

## 单集卡时量化（产能预算）

把「单集 1–2 分钟」落成可执行指标，避免对白过密、节奏拖沓：

| 指标 | 预算 |
|---|---|
| 单集剧本正文 | 约 300–500 字（动作行 + 对白合计） |
| 对白句数 | ≤ 10–12 句，每句 ≤ 15–20 字为宜 |
| 核心场景 | 2–3 个（开场钩子场景 / 爽点场景 / 结尾钩子场景） |
| 核心爽点 | 每集 ≥ 1 个 |
| 结尾钩子 | 每集 1 个（除结局外必留） |

- 写单集剧本先按上表「预算」规划，成稿后自查：超字数就删对白/合并场景，不要靠加旁白压缩节奏。
- 开场 10 秒（约前 50–80 字）必须完成「抓眼」——先抛冲突/反差，再交代设定。

## 风格对标：短剧导演大师分类

按类型对标导演，确定「创作类型命名 + 特点」作为风格参照。

### 都市爽剧 — 高峰
- 代表作：《The Divorced Billionaire Heiress》（20 万美元成本，北美 3500 万美元票房，收益超 170 倍）。
- 创作类型：出海向都市爽感叙事型——逆袭/反杀，女性崛起、豪门恩怨高频爽点，节奏紧凑、钩子密集，适配海外市场，低成本高收益。
- 命名：**出海爽感大师**。

### 古装甜宠 — 杨欢
- 代表作：《娘娘今日不上朝》《长公主不可以》（单部收益破 1800 万元）。
- 创作类型：轻喜向古装甜宠叙事型——甜宠氛围 + 轻喜剧节奏，公主/公子人设，轻松无虐、高甜互动，适配竖屏。
- 命名：**古装甜宠轻喜大师**。

### 古装爽剧 — 吴星星
- 代表作：《商女云洛溪》《绝世：病娇公子爱上我》（均获平台最高 S 级评级）。
- 创作类型：低成本高回报古装爽感型——古装逆袭、女强反杀，节奏紧凑、每集留钩子，人设极致鲜明。
- 命名：**古装爽剧大师**。

### 现实向反诈 — 李然
- 代表作：《反诈先锋之骗局拆解》（播放量破 8 亿次）。
- 创作类型：民生向反诈叙事型——真实案例 + 强情节，兼顾普法与娱乐，代入感强、真实接地气，收益渠道多元。
- 命名：**现实反诈收益大师**。

### 女性成长 — 张悦
- 代表作：《方夏》《戏精影后的自我修养》（全网播放累计破 10 亿）。
- 创作类型：独立向女性叙事型——独立清醒女性人设，女性创业/反杀/互助，有爽感又有深度，摒弃「恋爱脑」套路。
- 命名：**女性成长短剧大师**。

### 悬疑惊悚 — 吴星星
- 代表作：《叛逆俏冤家》《黑楼惊魂》（短剧版）。
- 创作类型：高反转悬疑惊悚型——紧张刺激氛围、反转密集、每集强悬念，聚焦密室/探案，付费转化强。
- 命名：**悬疑惊悚大师**。

### 复合类型（穿越+职业励志）— 林溪
- 代表作：《千金谋》（播放量破 7 亿，融合穿越、古代经商、励志成长）。
- 创作类型：反套路复合叙事型——打破单一题材壁垒，穿越 + 职业励志 + 古代经商，剧情反套路、人设新颖，爽感与成长线并重。
- 命名：**复合类型短剧创新大师**。

### 都市甜宠 — 杨欢
- 代表作：《我的猫系男友》《无法恋爱的夫君》（全网播放累计破 9 亿）。
- 创作类型：轻甜向都市情感型——都市男女情感痛点、治愈系甜宠互动，剧情轻松解压、台词细腻有氛围感，适配竖屏。
- 命名：**都市甜宠轻治愈大师**。

### 乡村擦边/乡村志怪 — 王磊
- 代表作：《媳妇井》《乡村叔嫂》《村霸复仇》（《媳妇井》热度 5300 万，单部收益破 1500 万元）。
- 创作类型：乡土向强情绪叙事型——乡村真实场景，擦边暧昧、志怪悬疑、乡土冲突，世俗接地气，挖掘邻里/亲属复杂关系，节奏紧凑、情绪拉满，适配下沉市场，单部成本 30–50 万元。
- 命名：**乡村强情绪大师**。

### 家庭狗血复仇 — 刘敏
- 代表作：《错爱半生：豪门复仇》《分家之战》《捉奸风云》（累计播放破 8 亿）。
- 创作类型：狗血向强冲突叙事型——出轨、财产争夺、偏心分家等世俗化冲突，极致情绪张力，每集强冲突钩子（捉奸/对峙/复仇反击），人设鲜明（偏心长辈/出轨伴侣/隐忍复仇者），适配下沉与中老年受众。
- 命名：**家庭复仇大师**。

## 短剧剧本输出约定

- 用 `story-development` 建项目目录，`正文/` 改为分集文件（`第01集.md`…）。
- 每集文件包含：集数、本集钩子（开场）与结尾悬念、核心爽点清单、对白与动作行。
- 分集大纲先列「每集功能 + 结尾钩子」，再逐集成稿；进度与钩子清单写进 `进度.md` 与 `伏笔表.md`。
