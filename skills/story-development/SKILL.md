# 故事策划与大纲（story-development）

把一句模糊的创意变成一份可直接动笔的策划案：梗概、主题、世界观、人物、结构、大纲、项目目录。

## 定位与适用

- 适用于：小说（长篇/中短篇/网文）、电影/电视剧/话剧剧本、微短剧，以及小说改编剧本的前置策划。
- 与其它 skill 的关系：本 skill 负责「策划 + 结构 + 大纲」，产出后交给 `novel-writing` / `screenplay-writing` / `short-drama-writing` 动笔；结构库（《经典剧作结构大全》）是跨格式共享的，其它 skill 会引用它。

## 策划流水线

按顺序执行，每一步产出写入项目目录：

1. **创意访谈**：题材、篇幅、目标读者/平台、风格、核心爽点/情感点未明确时，用 `ask_user_question` 澄清（不要替用户做主）。
2. **一句话梗概（logline）**：谁 + 在什么处境下 + 想要什么 + 遇到什么阻碍 + 为什么现在必须行动。一句话讲清卖点。
3. **主题立意**：这部作品「到底讲什么」，一句话点明（逆袭/复仇/救赎/爱恋/成长/真相…）。
4. **世界观与设定**：时间/地点/规则/超自然体系（玄幻/科幻/奇幻尤其要写清规则与代价）。
5. **人物设定**：主角（缺陷 + 需求 + 弧光）、对手/反派（动机）、盟友、关键关系；建立人物表。
6. **选结构**：从《经典剧作结构大全》里挑一个适配结构（见下），作为全篇骨架。
7. **分章/分场大纲**：按所选结构拆成章节/场次/节拍，标注每处的功能（建置/激励事件/中点反转/低谷/高潮/结局）。
8. **输出项目目录**（见「输出约定」）。

## 经典剧作结构大全

选结构时按题材与篇幅就近取材；短剧优先「爽剧打脸 / 悬疑三幕反转 / 极简爆款」，电影优先「三幕 / 英雄之旅 / 救猫咪」。

### 1. 三幕式结构（最基础、最万能）

几乎所有电影、短剧、小说都在用。

- **第一幕：开端（建置）**——交代人物、世界、日常，出现激励事件打破平静。
- **第二幕：发展（对抗）**——主角尝试解决问题，不断受挫，中点反转，陷入最低谷。
- **第三幕：结局（解决）**——最终决战、真相揭露、危机解决，完成主题闭环。

### 2. 英雄之旅（神话结构，好莱坞最爱）

约瑟夫·坎贝尔提出，适合逆袭、成长、冒险题材。

平凡世界 → 冒险召唤 → 拒绝召唤 → 遇见导师 → 跨越门槛 → 考验、盟友、敌人 → 进入洞穴深处 → 严峻考验 → 奖赏 → 回归之路 → 重生 → 满载而归。

### 3. 八步叙事结构（精简版英雄之旅）

主角 → 缺陷/需求 → 意外闯入 → 被迫上路 → 遇到盟友与对手 → 关键试炼 → 灵魂黑夜 → 解决与新生。

### 4. 救猫咪结构（商业爆款专用）

布莱克·斯奈德，特别适合短剧、爽剧、网大。开篇让主角做一件「救猫咪」的事，快速立住人设；10 页一个钩子、30 页反转、60 页高潮。

开场画面 → 铺垫呈现 → 激励事件 → 争执（要不要行动）→ 第一幕转折点 → B 故事上线（爱情/友情/主题）→ 欢乐与挑战 → 中点反转 → 坏事降临 → 灵魂黑夜 → 突破与觉醒 → 高潮决战 → 结局。

### 5. 五幕剧结构（古典戏剧结构）

莎士比亚、话剧常用：开端 → 上升 → 高潮 → 回落 → 结局。

### 6. 目标-阻碍-行动-危机-结局（极简爆款结构）

短剧、短视频剧最实用：目标 → 阻碍 → 行动 → 危机（绝境）→ 结局（反转/胜利）。

### 7. 悬疑三幕反转结构（悬疑剧专用）

抛出谜面 → 误导线索 + 伪解答 → 真相反转 + 闭环。

### 8. 爽剧打脸结构（微短剧通用）

受辱/低谷 → 获得金手指/觉醒 → 初次打脸 → 更大危机 → 终极翻盘 → 身份曝光/全场震惊。

## 输出约定

为每个项目建立如下目录（长篇尤其要严格）：

```
<作品名>/
  大纲/
    梗概.md         # logline + 主题 + 一句话卖点
    分章大纲.md      # 或 分场大纲.md（剧本/短剧）
    结构.md         # 所选结构 + 全篇骨架标注
  设定/
    世界观.md
    人物表.md        # 单一事实源，随写随更新
    时间线.md
    伏笔表.md        # 埋设/回收记录
  正文/             # 小说：第001章.md …；剧本：按场/集
  进度.md           # 已写/下一章/总字数
```

- 人名、术语、世界观一旦确定就写进设定文件并全程复用，保持一致。
- 大纲不是终稿，动笔中发现的改动要回写到「分章大纲.md」与设定文件。

## 长文本项目

长篇小说采用「增量落盘 + 分章文件 + 单一事实源设定表」创作。项目目录、每章起草流程、字数预算、进度与伏笔管理详见 `novel-writing` 的「长篇小说增量创作协议」；本 skill 只负责在策划阶段把上述目录与设定表建好。
